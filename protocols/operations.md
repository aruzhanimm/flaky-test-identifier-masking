# Masking operations and robustness protocol

Scientific-content projection of the 15 October 2026 extension protocol. The original main results were already known. This is a fixed post-hoc exploratory extension, not an independent confirmatory study or public preregistration. Its historical hash is retained in `evidence/publication/projections.json`.

Keep the 1,051 observations, labels, repository groups, LR/TF-IDF parameters and paired splits unchanged. Report all comparisons without selecting a favourable subset or adding confirmatory p-values.

1. **Reproduction audit.** Reparse retained target diagnostics, independently recompute metrics, inspect saved splits and reproduce main original/full predictions, vocabularies and coefficients. Trace every changed case to the corpus. Do not claim Java/Docker execution.
2. **Operations.** Evaluate all eight subsets of T (test class/method replacement), R (repository URL/name/component replacement) and P (whole-path replacement). Original must be text-identical to the corpus original; full must be identical to its masked text. Preserve operation order and exception protection. Operations can overlap semantically: R may replace a name within a path even without P. They are not independent causal information sources.
3. **Changed cases.** Inspect all 56 changed main decisions across all ten affected groups. Retain source/format, project support, lengths, diagnostic text and metadata. Apply each fitted original model to masked input and each fitted masked model to original input on held-out projects. Decompose score-contrast change along original-model/original-input → original-model/masked-input → masked-model/masked-input. The latter term combines vocabulary, IDF, normalisation and coefficient changes; it is an algebraic path, not a cause of flakiness. Retain top token contributions for all cases.
4. **Collection controls.** Report category×format and category×project tables, including empty cells. If two categories each occur in at least three groups within one collector family, run a separate paired subtask using only that family; the selected subtask is Surefire OD/TD. State exact formats as well as the XML/TXT family. This subtask does not remove general selection bias or sparse TD coverage.
5. **Additional learner.** LinearSVC uses the same word TF-IDF, C=1, balanced weights, dual=auto, squared_hinge, max_iter=10000, tol=0.0001 and seed 20261013. Evaluate original/full on all original folds. Repeat its fits and check predictions/vocabulary/coefficient hashes. Stop and disclose convergence problems rather than silently tuning parameters. This compares linear objectives, not neural representations.
6. **New evidence.** Inspect public catalogs for compatible Java target-failure logs, labels, full revision/project identity and overlap exclusion. Metadata or test code alone is insufficient. New records from the same collection are not independent-source external validation. Record eligibility decisions and remaining prerequisites without claiming that no suitable data exist anywhere.
7. **Validation.** Save all predictions and parameters, recompute F1 independently, verify splits and exact main-pair reproduction, and account for every changed case. Preserve execution failures and subsequent corrections. The original extension first encountered a NumPy-integer JSON-serialization error; the serializer was corrected and the full experiment repeated without changing the scientific settings.
